# Third-party notices

Datum's own code is under the MIT licence (`LICENSE`). The assets below are not
Datum's: they are vendored in the repository or copied beside the bundles at build time, and
each keeps the licence its authors gave it. A package that vendors a new asset adds a
row here and ships the licence text beside the files, as the rows below do.

## Vendored in the repository

Datum ships one official look, the `datum` binding, and it vendors nothing from a design system.
The nine reference bindings under `bindings/<id>` (alberta, bootstrap, fluent, gcds, govuk, nova-scotia,
ontario, quebec, uswds) are demonstrations and starting points: each draws Datum's components in
one design system's own markup and **pins that design system's release as a `devDependency`
alias in its own package** (`bindings/<id>/package.json`, installed by `npm ci` there, never
committed, never bundled into the binding). A host that draws a form with a binding supplies the design system's own
stylesheet, script and fonts itself; the binding states what it needs (`binding-check.json`).

Datum's reference bindings are not accessibility claims about any design system: each binding is
checked for integration with Datum, never for the design system's own conformance.

## Copied beside the bundles at build time

Taken from npm packages when `packages/datum` builds (or, where the row names another
package, when that package builds into its own `dist/`), never committed
(`dist/` is ignored). The packages carry their own licence files, and each copy keeps
the licence of its package beside it.

| Asset in `dist/` | From | Licence |
|---|---|---|
| `fonts/DejaVu*.ttf` (the faces the PDF module embeds), with `fonts/LICENSE` | `dejavu-fonts-ttf` | DejaVu Fonts License (Bitstream Vera + Arev, free) |
| `pdfjs/` (worker, standard fonts, CMaps, wasm decoders, ICC profiles), with `pdfjs/LICENSE` | `pdfjs-dist` | Apache-2.0, with the licences of the bundled data (Foxit, JBIG2, OpenJPEG, qcms, QuickJS) in their folders, and GPL-2.0 with the Liberation font exception for the four Liberation Sans faces (see below) |

The four Liberation Sans faces in `pdfjs/standard_fonts/` (`LiberationSans-Regular`, `-Bold`, `-Italic`, `-BoldItalic`) are pdf.js's standard fonts, copied unmodified. Their licence is the GNU General Public License, version 2, with the Liberation font exception: a document that embeds the font does not by itself become covered by the GPL (exception (a)); exception (b) adds a source-access term for object code in a physical product. The text, with the GPL 2.0 it refers to, is `pdfjs/standard_fonts/LICENSE_LIBERATION` beside the files; the same text sits beside them in every artefact that ships the folder (the npm tarball, the bundles release asset, the `datum-pdf` jar, the `argusvane-datum-assets-pdf` wheel). The fonts are separate files distributed alongside Datum's MIT code and are never linked into it; Datum's own code stays under the MIT licence.

the licence text of every package it carries and the legal comments the bundler found in them; the
bundles hold none of that text, so a page downloads none of it. The icon set keeps Font Awesome's
banner inside the file as well, and its licence file ships in the plugin's `dist/`.
