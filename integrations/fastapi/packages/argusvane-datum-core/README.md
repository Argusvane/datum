# argusvane-datum-core

The framework-free core of Datum for Python. It holds the canonical writer, configuration validation, the forms, submissions, builder, PDF and timestamp services, hooks, events and checks, over `argusvane-datum-sandbox`, which runs the programs. It imports no web framework; each optional capability lives in a subpackage behind an extra.

Part of the Datum for FastAPI workspace; see `integrations/fastapi/` in the repository.
