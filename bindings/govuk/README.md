# @argusvane/datum-binding-govuk

The GOV.UK Frontend binding for Datum: it draws Datum's components in design-system.service.gov.uk's own markup, pinned to release 6.6.0 (the `govuk-frontend-6.6.0` devDependency alias; updating it is a manual refresh). Datum ships none of GOV.UK's files: the host supplies the stylesheet, optionally `all.bundle.js`, and the page font (GDS Transport is licensed for GOV.UK services and is never shipped here).

Datum is not affiliated with or endorsed by the Government Digital Service (UK). GOV.UK Frontend is theirs; this binding is an independent reference for it.

## What it draws

- Fields: text, textarea, number (a text box with a numeric keyboard, never `type="number"`), select, radios, checkboxes, a single checkbox, date input, button.
- Containers: fieldset, button group, tabs (strip, the contents list under the tablet breakpoint, flat for print), a data grid as stacked fieldsets.
- Form level: error summary (heading at `state.headingLevel`), language navigation, a journey page's heading (at `PageState.headingLevel`) and buttons, a Check answers page as GOV.UK's check answers pattern (a `govuk-heading-m` per step, a `govuk-summary-list` with Change links named in visually hidden text, a missing answer's "Enter …" link, a data grid's row as a `govuk-summary-card`; reference case `summary-list-check-answers`), the host's receipt as a notification banner (the success variant with `role="alert"` for a success, as GOV.UK's template; its banner script is not started, the renderer moves focus to it).
- Warnings and info as GOV.UK warning text and inset text, never as errors. A journey's "worked out" line as hint text. Pending and tooltip are `degraded` (GOV.UK has neither: the renderer folds the words into the hint; the field's wrapper carries `aria-busy`).
- Everything else (steps, files, signatures, chrome parts) is Datum's, tinted with GOV.UK's colours through `fallbackTokens`, and listed in `unsupported()`.

## Tiers

Tier 1 only: every GOV.UK component this binding uses is plain HTML and CSS, so Datum's behaviour (answers, checks, focus, the count, the reveal) drives GOV.UK's markup directly. There is no tier-2 type and no `FormPlugin`, so no `tests/tier2/` baseline to sign off.

## The design system's script

GOV.UK's `initAll({ scope })` is started on the form element when the host loads the script and the page body carries `govuk-frontend-supported`; only `govuk-button` is opted in (the other components look elements up through `document`, which a shadow root hides) and the rest stay on GOV.UK's no-JavaScript baseline, which is complete. The listeners the start leaves on `window` and `document` are removed on unmount. Details and every side effect outside the form: [docs/side-effects.md](docs/side-effects.md).

## Use

```ts
import { bindings } from "@argusvane/datum";
import { createBinding } from "@argusvane/datum-binding-govuk";

bindings.register(bindings.fromFactory(createBinding), { assets });   // govuk-frontend.min.css, and all.bundle.js as a classic script, of the one pinned release
```

The package's `exports` point `import` at the TypeScript source (`src/index.ts`), for a bundler that compiles TypeScript. A page without a bundler loads `dist/govuk.iife.js` (`npm run build`; the global `DatumBindingGovuk`), or imports `dist/govuk.js`. The page's `<body>` carries `govuk-frontend-supported` for the script to start. The CSP, CORS and Trusted Types a host page needs are in [docs/host-security.md](../../docs/host-security.md).

## Checks

```
npm run kit:check      # package, build (budgetKb 10), tokens, equality, behaviour, datum-binding-check
npm run reference      # rewrites reference/*.html from the pinned release's Nunjucks macros
node src/checks.mjs    # the binding's own browser checks (notices, scripts, focus, headings, worked-out line)
```

`reference/*.html` are generated by `reference/generate.mjs` from GOV.UK Frontend's own templates; for a shipped fixture the generator asserts that its render equals the fixture HTML the release ships. Each file's first comment cites its source.
