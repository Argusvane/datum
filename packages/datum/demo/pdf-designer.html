A host page with the PDF layout designer inside it

All demos The form builder

<datum-form-builder workspaces="pdf"> is the form builder over the form's PDF layouts alone: one tab per layout on its bar, the tab's menu to rename, copy, default or remove it, + to add one, and Preview PDF beside them. A custom layout is designed on the page sheet, each bound field previewed over the sample answers; + can also populate an existing PDF form — a file you upload, or one this page provides through pdfTemplates — whose fields become the layout's tree: pick a field's box on the page and say what fills it in the inspector. A PDF with no fields is populated through areas drawn over its pages, the pages shown through datum-pdf-pages.js (pdf.js) beside the bundle.

pdf="auto" loads datum-pdf.js beside the bundle on the first preview, so the bytes come from the real kernel. Every change reaches the page as one datum-pdf-layout-change event carrying the definition with its pdf block.
